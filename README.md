
# Project 1 Reflection

For this project, I learned a lot more about how different SwiftUI elements can work together to create a complete app instead of just individual exercises. One of the biggest things I learned was how to use `NavigationStack` and `NavigationLink` to connect multiple views. I also got more comfortable creating reusable styles and structs rather than repeating the same formatting over and over. This was especially helpful for keeping my navigation buttons and About Me cards consistent.

The most challenging part for me was figuring out how everything should be organized and making sure each view worked correctly within the main ContentView. I also had to experiment with sizing, spacing, colors, and the Mac preview to get the app to look the way I wanted. For my design, I chose a softer pastel blue color palette and kept the layout fairly simple so that all of the different views still felt like they belonged to the same app. I enjoyed choosing images and content for the cards because it gave me a chance to make the project more personal. Overall, this project helped me understand SwiftUI better and made me more comfortable with building and styling an app with multiple views.
